# 24 层魔塔

[在线游玩](https://zqpei.github.io/game/mota/)

在仓库根目录运行 `python3 -m http.server 8765 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8765/`，即可在本地游玩。

- 方向键移动。商店用 ↑ / ↓ 选择，空格或回车确认，Esc 离开。
- S 打开存档，A 打开读档。存档保存在当前浏览器。读取旧档前会备份当前进度。
- 拿到相应道具后，L 查看怪物手册，J 使用楼层传送器，T 打开道具栏。
